# P2 + P3 · grupos

Crear grupo, consultar miembros y aceptar invitación mediante la API HTTPS autenticada del VPS. La UI consume puertos de P5; P3 comprueba autorización y realiza las transacciones SQLite.
La app no accede directamente a tablas ni archivos del servidor.
Primera entrega: A invita a B y un usuario ajeno no puede acceder al grupo.
